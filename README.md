# Airline Management System Database

## Overview

A comprehensive Airline Management System designed using Database Management System concepts.

The system manages:

- Flight Scheduling
- Passenger Bookings
- Ticket Management
- Aircraft Maintenance
- Employee Management
- Baggage Tracking
- Payment Processing

## Technologies

- SQL
- Database Design
- ERD Modeling
- Normalization (1NF, 2NF, 3NF)

## Features

- 25+ Database Tables
- Fully Normalized Schema
- Foreign Key Constraints
- Reporting Queries
- Airline Operations Management
